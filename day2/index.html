Tutorial

Variables are the core fundamental of any programming languages. It's a very important concept and it's very easy to understand once you think of it this way -> A Variable is a container used to hold / store value or values. Hence when we refer to that variable , we're actually referring to the value it stored.

Variables serve as a pointer that points to the value in the memory location on our computer. To not really get into some archaic details, let's make use of the fact that JavaScript is a high level programming language. Learning about how a variable holds a value is not really important since JavaScript takes care of all of that as opposed to a low level programming language.

So, let's really get our feet wet with understanding variables.

Think of a variable as what we use in programming world to hold a data / value / expression. (More on expression later)

Let's see some example, so we can get a better understanding of variables and what it's used for

Suppose i wanted to print out an address of a person using the log method of the console but the whole address is so long and imagine if i wanted to use the address in some other part of my program? I have two options, i can either copy and paste or type manually. Now, you might think, "Why not just copy and paste? " Imagine it's not exactly a simple project but a complex project, you'll have to find where you actually print out the address.

There are alot of other reasons why variables are so important that you as a programmer will figure out yourself when you write programs.

Note

Another example is when you've used the address (from our earlier example) in many places in your program, then you want to change the last word in the address... You'll have to find all the address and remove the last word one by one which might take alot of time...

Remember, always used variable to store your data

Now, let's look at the syntax for creating a variable and giving it a value (we love using the word "declaring a variable" and not "creating a variable", i use it here for simplicity):

var variable_name = value

or

let variable_name = value

or

const variable_name = value

We use the above syntax to create a variable. The var, let, and const are the keywords used to create our variable. The variable_name is a unique name that we give to our variable. The value is (obviously) the value of our variable

Note

Picking a variable name carefully is so important. For starters, your variable name must be descriptive and must not be a keyword (this is to avoid conflict, so that the interpreter won't think of your variable as a keyword). Your variable name must not contain any of the arithmetic operators and other operators (logical and relational). Your variable name can't be a built-in object such as console (more on objects and api's later)

We'll talk about all of these later in the course. We've already seen some keywords such as var, let, const. For more keywords in JavaScript, kindly visit:

About the operators, just note them for now (we'll discussed about operators in the future) : + , - , * , ** , &&, ||, ! , >>, <<, %, ~ , ( , ), /

Other special characters should be avoided generally. These characters include: ', ", { , }, \ , @ , # , $ , ` , . , ,

Before we talk about the data types in JavaScript, let's learn about naming convention when picking your variable name:

Camel Case

This style is the only recommended style for JavaScript programmers. We (JavaScript programmers) use camel case when naming our variable. The camel case is a very simple to understand style. If it's a word, just use it like this:

hello

If it's two words, write them together, but with the second word beginning with capital letter to indicate the start of another word:

helloJohn

A real programmer reading this would quickly understand that you actually wrote two words "Hello" and "John" and not one word "helloJohn". It's up to you to decide if you like this approach or not. FYI: Almost all JavaScript devs use this style of naming convention when naming their variables.

Watch carefully the last example of camel case below:

welcomeToTheWorldOfJavaScript

FYI: The name "camelCase" comes from the look of your variable name once you used this style. It looks like a camel 🐫

Snake Case

Snake Case is used by people using other languages like python e.tc. This is the de-facto of all python devs. To use a Snake case as your naming convention, join your words with underscore if it's longer than 1.

Example (1 word):

hello

Example (2 words):

hello_user

Example (6 words):

welcome_to_the_world_of_javascript

The snake case is quite easy to understand and if you've noticed, all the words i used are lowercased. This is just a matter of preference. But note that, most snake_case variable names are lowercased in the programming realm. (Most people that use snake_case used lowercased letters for their variable name).

This style is known as snake_case because it obviously looks like a snake. Don't beleive it? Remember how snake look like in games like Snake Xenxia.

There are other naming convention but those two discussed above are the most important.

Now that we've knew how to name our variable, let's talk about the different between let, var and const

Var

Var is the oldest way to declare your variable. But note that, it has alot of limitation compared to let. Var is used to declare variables that can be reassigned a value. For example, let's say i declared a variable named "age" with the value of 120, i can reassign it with the value of 121 and it'll still be a valid code. Check out the code below:

...
var age = 120 //the first value
age = 121 //same variable but with a different value
console.log(121);
...

The only limitation with this was that it's not block scoped. Block are what we used to group a code. (We call them "Block of codes" because they're grouped with blocks). Take a look at the below code, you might expect the output to be "John" but the ouput is "Joseph":

...
var name = "John"

{
    var name = "Joseph"
}

console.log(name);
...

However, variables declared using the var keyword are function scoped. The value are not leaking if they're enclosed in ( and ). Var also has something called Hoisting. Just search it on google if you're interested but generally i 100% recommend using let over var. Take a look at the below code, it fixes our earlier problem:

...
let name = "John";

(function(){
    let name = "Joseph"
})()

console.log(name);
...

You'll notice that the let name = "Joseph" is enclosed in brackets ' ( ' and ' ) '

Let

Using let and var are literally the same. They're both used to declare variables whose value can be reassigned except 'let' fix the hoisting problem with var and it's also block scoped which is so great for programmers alike. It also uses less memory then var and it reduce encountering some weird bugs that can't be prevented if you're using var.

Note

Bug is a way programmers used to refer to error in programs. The name actually came from a real bug that causes a malfunction in a computer. Ever since then, programmers adopt to calling errors in programs "A Bug".

To use a let, just follow the below syntax:

let variable_name = value

So, suppose we want to create a variable named "name" with a value of "John Doe". We create the variable as below:

...
var name = "John Doe"
console.log(name);
...

Let's see if our problem from earlier (using var) is fixed (with using let):

...
let name = "John"

{
    let name = "Joseph"
}

console.log(name);
...

And our output is now "John" and not "Joseph". I know all of this is weird, but knowing this matters alot. As we'll learn more in the future on "Global Variables" and "Local Variables". But knowing the difference between 'var' and 'let' is the key to understanding them.

Const

Constants variables are variables we do not want to change their value once we've assigned a value to them. In other words, they're constants.

Constants actually works the same like "let", but with just an exception that once you assign it a value you can't change the value throughout your program.

"const" are especially important if we don't want to change our variable value throughout our entire program. Constants also uses the least memory of computer. Let's look at an example:

...
const name = "John";

{
    const name = "Joseph"
}

console.log(name);
...

This works so well like 'let' but with the least memory being used. Since once you gave it a value, you can't change it... JavaScript allocate a fixed memory compared to 'var' or 'let'

You'll encounter an error if you try to run the below code (notice how i tried to gave it a new value):

...
const name = "John";
name = "Joseph";

console.log(name);
...

And that marks the end of the whole "let" vs "var" vs "const".

Note

I personally recommend using 'const' or 'let' and always avoid using 'var'. 'var' was oldest with alot of bugs (e.g hoisting) and 'let' was introduce in later version of JavaScript to fix the bugs.

Also, when naming your variable, avoid giving it a space. (Don't forget, we JavaScript programmers use camelCase)
