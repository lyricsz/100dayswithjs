The Prompt Method

The prompt method of the window works the same way as the alert method. Infact all window functions(also method) works this same way. We can call them in two different ways, by appending it with window. [window.alert()] or by just calling it [alert()]

Since prompt is a method of the window object (We'll stick with API once it is explained in the future), that means we can call it in two ways:

prompt();

or

window.prompt();

Let's say we called it , what do we expect? Well, if you try calling it... The user is presented with a input box, so the user can type in a text or anything. The problem this posed was, if i enter a text during the execution of the program, how will i know what text i entered once i've entered it? How can i make use of this user data in some part of my program? Well, this is where we learn more about the return value. A function can return a value when it is called. You can make use of this return value however you like:

<!DOCTYPE html>
<html lang="en">
    <head>
        <title> Prompt Method - Example </title>
    </head>
    <body>
        <script>
            console.log("Your name is ", prompt());
        <script>
    </body>
</html>

When you run the above code, the prompt method is called which presents the user a box to enter a text, whatever the text the user entered, it is return to where the function is being called. Enter any name and check your console to ensure everything is working as intended.

But this isn't a well structured program, was it? Once we've got the return value we just log it to the console and there's no other way to make use of the value in other part of our program. We can fix this by storing the return value to a variable. We'll be using let keyword this time to declare our variable.

...
let name = prompt();
console.log("Your name is ", name);
console.log(name, " is learning JavaScript.");
...

You might be wondering why we're using commas instead of string concatenation operator (+), using comma is provided to us by console.log... Console.log is the defacto way of printing message for debugging or learning purpose.

We understood that we're suppose to enter our name, but our program must be implemented for any user, in any space and time in this world. To inform the user any message related to the expected input, you can pass this message in as a parameter (we've discussed about this when learning about functions). Let's take a look at our modified example:

...
let firstName = prompt("What is your first name?");
let lastName = prompt("What is your last name?");
let favLanguage = prompt("What is your favourite language?");

console.log("Your name is " + firstName + " " + lastName);
console.log(firstName, " is learning JavaScript.");
console.log(firstName, ", you like ", favLanguage, " language.");
...

You can also pass in default value as a second parameter to the prompt method:

...
let firstName = prompt("What is your first name?", "John");
let lastName = prompt("What is your last name?", "Doe");
let favLanguage = prompt("What is your favourite language?", "Mandarin");

console.log("Your name is " + firstName + " " + lastName);
console.log(firstName, " is learning JavaScript.");
console.log(firstName, ", you like ", favLanguage, " language.");
...

I'ld advise you investigate the above code and ensure you've understood how it works before moving on to the next section.

The Confirm Method

The confirm method is used to get Yes or No answer from the user. You've come in contact with these type of dialog almost every time. Facebook for example, when you tried deleting a post it sents you a dialog to give you a last warning notice if you're sure you really want to delete it. This Yes or No boxes is so common and can even be customized using DOM as we'll explore this part in the future.

The confirm method returns true or false based on the user input. If Yes , it returns true. If No , it returns false. We can make use of this in a coditional statement... We'll learn about how to make decision based on condition in the future.

...
let playingGame = confirm();
console.log("Are you playing game? " + playingGame);
...

When you clicked on Okay, it returns true. Otherwise, it returns false. It also accepts parameters just like the prompt method. Let's revised the last example:

...
let playingGame = confirm("Are you currently playing game? ");
console.log("Are you playing game? " + playingGame);
...

There are alot of things you can do with the return value (the value being returned in confirm method is boolean value while that of prompt is a string value) here. We'll came across such examples when learning about conditionals.

You can also accept text from the user using HTML input elements. We'll discussed this in the next section. But before that, let's learn about the typeof keyword and type conversion.

Typeof and Type Casting

To know what type of data we're using , we can check the program and try to make deduction from it or we can explicitly use the typeof keyword to know what type of data we have in our variable.

Take a look at below code, what type of data is the variable's value?

...
let age = 10;
alert("Your age is " + age);
...

To explicitly know what our type our data is, we make use of the typeof keyword. Follow the typeof keyword with the variabla name (or the data you want to check it's type).

...
let age = 10;
alert("Your age is a " + typeof age);
...

This opens alot of opportunity, we can now check the data type for all data that we have. Remember that each data type can only be from the data type listed in day 3. You can revisit day 3 lesson if you think it's necessary to review.

First of all, let's take a look at the data type of the return value of a prompt function.

...
let test = prompt("Enter anything: ");
console.log("The data type of prompt return value is ", typeof test);
...

Let's go ahead and try that of confirm to ensure it indeed return a true or false to us.

...
let test = confirm("Did you want to continue learning JavaScript? ");
console.log("The data type of confirm return value is ", typeof test);
...

And we indeed get Boolean (has only two value -- true or false). Let's go over another example to get a better understanding of this keyword:

...
const name = "John Doe";
const age = 24;
const hobbies = ["Dancing", "Hacking", "Cooking"];
const programmingLanguages = {
    favorite: ["Python", "JavaScript", "SQL"],
    nonFavorie: ["C", "Pascal", "MySQL"]
};
const over18 = true;
const height = null;
const girlfriend;

console.log("Type of name ", typeof name);
console.log("Type of age ", typeof age);
console.log("Type of hobbies ", typeof hobbies);
console.log("Type of programming languages ", typeof programmingLanguages);
console.log("Type of over 18 ", typeof over18);
console.log("Type of height ", typeof height);
console.log("Type of girlfriend ", typeof girlfriend);
...

If you run this program, you'll encounter an error. This is because you have to assign a value to a constant variable. You can't just declare a constant variable without assigning it a variable, the interpreter will flag this as an error.

Let's try to fix that by using let instead of a const:

...
const name = "John Doe";
const age = 24;
const hobbies = ["Dancing", "Hacking", "Cooking"];
const programmingLanguages = {
    favorite: ["Python", "JavaScript", "SQL"],
    nonFavorie: ["C", "Pascal", "MySQL"]
};
const over18 = true;
const height = null;
let girlfriend;

console.log("Type of name ", typeof name);
console.log("Type of age ", typeof age);
console.log("Type of hobbies ", typeof hobbies);
console.log("Type of programming languages ", typeof programmingLanguages);
console.log("Type of over 18 ", typeof over18);
console.log("Type of height ", typeof height);
console.log("Type of girlfriend ", typeof girlfriend);
...

Null is a type of object. What's weird is that Array is also a type of an object. This is a bug and not exactly a coincidence. You'll learn more about these two and their similarities and differences in the future.

The typeof evaluates the data in front of it. This is one of the main reason why we called typeof an operator.

Type Conversion is when the interpreter tries to convert a data from one type to another for us. This usually leads to bugs as we (the programmer) are confused of what exactly is going on when we expect something to behave as a string but it's acting as a number.

Type Casting is when we convert a data from one type to another type or the same type explicitly. I've been mixing these two important concepts with each other since, i apologize for that.

We can Type cast in JavaScript using the provided function given to us. To type cast any data type to another data type, check out below available functions to type cast and their usage:

Number
The Number method takes a parameter, converts the parameter to a data type of number and returns the value. We use this mostly to convert a data type from a string to a number. To call a Number method, just call it the same way you called methods. Let's check out below example, we try to convert a string that was returned by a prompt to a number. Please note that if it can't be converted to number, we get Nan (Not-A-Number): ...
let age = prompt("Enter your age: ", 20);
age = Number(age);

alert("Your current age is " + age);
alert("Your age is a " + typeof age);
...
String
The string is used to convert a data to string. We can do this with Numbers e.t.c. We'll learn more about each data type in the future, so it's completely fine if you haven't got the hang of it... Let's try converting a number to string using the string method. ...
let age = 10;
age = String(age);

alert("Your current age is " + age);
alert("Your age is a " + typeof age);
...

These are the basics type casting that you should be aware of. As we learn more about numbers, we'll see hoe type conversion happens in JavaScript... and some really buggy interpretation of our program.

Before we finish these day 5 lesson, try converting boolean values to number or string. What happens if you try Array? Or Null? Or undefined? Or Nan? Or others... Remember, never quench the curiosity in you, Adieu.
