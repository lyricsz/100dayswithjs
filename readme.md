# 100 days with JavaScript

## Introduction

| Hello and welcome to a 100 days challenge with JavaScript. Throughout this open-sourced project (MIT licensed), we'll learn JavaScript frontend and backend for web development through hands-on project. This approach is A Project A day approach. 

## About

| This repo is the git repository for a 100 days challenge with Js. The site for the repo can be found on [100 Days with JavaScript]("https://lyricsz.github.io"). You can contribute to this repo by adding your content (tutorial) or fixing contents that have some errors or bugs, or you can add your view on a particular subsection or section. To do that, you can fork this repo and push to us the modified branch.

## The Challenge
- If you're a beginner, intermediate, expert in JavaScript... you can benefit alot with this tutorial. The tutorial not only teaches you how to code but adds a project at the end of the lesson.
- All learners planning to join the challenge are recommended to create a github repository to store and save each project they created. This will also boost their resume.
- In this challenge it is recommended that you start with day 1 whether you're a beginner or expert alike, this challenge was created for all. 
- Concepts and Projects learned in this challenge can easily be applied to projects that uses different programming language.
- We'll not only be learning JavaScript in this challenge (also known as Vanilla JavaScript) but also get our hands dirty with Libraries that helps simplify things and how they're being used in web development. 
- The challenge has a Whatsapp group where you can meet other learners to collaborate, share ideas, discuss or simply mingle. You can head over to the Whatsapp group now if you want. (There are other benefits that are unlisted)
- More coming... Stay tuned
