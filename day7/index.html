Tutorial

Reviewing the past lesson (lesson 6) is so crucial for this lesson. If you haven't done so yet, kindly do so now. If you've forget some of the concepts taught in the previous lesson, don't worry you'll be able to follow the lesson. Knowing about how to get an element (node) using any of the selectors is crucial to continue. We'll use the getElementById method the most in this lesson.

Let's visit a simple example - Modifying the content of a paragraph element.

const pEl = document.getElementById("p");
pEl.textContent = "Hello World!"

Assuming there's an element in your page with the id attribute of p, the element's content will always be replaced by "Hello World!". Only one element has to have the ID since ID's are unique. But then the question this poses is this... What if you don't want to only modify the content (A quick refresh -- to add html directly as the content of the selected node, just override the innerHTML method to match the html code. E.g pEl.innerHTML = "<i> Hello World! </i>"), but also the CSS or the function (JS) of the node (element). You can do this in JavaScript as easy as possible. Just select the node and assign / override the CSS or JS.

To change the CSS of an element, we can follow the below syntax (With pEl being the selected element).

pEl.style.property = "new property value";

This is just the skeleton. The property here can represent all property. The value also represent the valid property value you want to assign to that property. You can change the CSS of any element using this method. Let's try out an example:

const pEl = document.getElementById("p");
pEl.textContent = "Hello World!" pEl.style.color = "green";

In the above example, we can notice that after selecting the element with the ID of "p", not only did we change the content of that element we also modify the CSS of that element by changing it's color to green. You can of course change other properties of the element. But this is where it gets interesting, what of how to change the values of properties like 'background-color'? We can't use "-" as a part of a variable name. To fix this, we can use the well known naming convention called camelCase. So instead of using background-color, we can use backgroundColor. This is the same for all CSS properties that contain a "-". Let's try out an example:

const pEl = document.getElementById("p");
pEl.textContent = "Hello World!";
pEl.style.color = "red";
pEl.style.borderRadius = "20px";
pEl.style.backgroundColor = "green";

A valid full listing code is given below just in case:

...
<!DOCTYPE html>
<html lang='en'>
<head>
    <title> A Simple Webpage </title>
</head>
<body>
    <p>Howdy?</p>
    <script>
        const pEl = document.getElementById("p");
        pEl.textContent = "Hello World!";
        pEl.style.color = "red";
        pEl.style.borderRadius = "20px";
        pEl.style.backgroundColor = "green";
    </script>
</body>
</html>

In this example, we saw our we can use camelCase naming convention to fix the problem we encountered with property that have more than one word. Always take note of the capitalization, while the copying and pasting feature is there to help you, rarely use it... instead type the code by yourself. As a friend of mine used to say "Get used to typing".

Let's move on to how we can modify an element's (node) attribute. The element attribute can be a valid attribute or not. What matters is that you know what that attribute's value is (the new value) as it will override the previous attribute's value. Let's try out an example: (We use a little bit of CSS here to explain things)

...
<!DOCTYPE html>
<html lang='en'>
<head>
    <title> A Simple Webpage </title>
    <style>
     .red {
         color: red;
    }

     .blue {
         color: blue;
    }
</style>
</head>
<body>
    <p class="red" id="p">Howdy?</p>
    <script>
        const pEl = document.getElementById("p");
        pEl.textContent = "Hello World!";
        pEl.setAttribute("class", "blue")
    </script>
</body>
</html>
...

In the above example, we make use of two classes in the CSSS selectors. If an element has a class of red, we set it's color to red ,else , if it's .blue we set it's color to blue. However, we initally set the element (P element) class to red, then we override this using this line of code -- pEl.setAttribute("class", "blue") --. This line of code calls the setAttribute method of an element, we pass in the attribute first (in double quote -- " ") , then the second argument is the value of that attribute.

To better understand this clearly, let us add CSS to an element using the style attribute. We'll be changing things a bit. In the below example we'll add the style using setAttribute method (Remember from our HTML lessons, we can use the style attribute to add a CSS (Inline CSS) to our element).

...
<!DOCTYPE html>
<html lang='en'>
<head>
    <title> A Simple Webpage </title>
    <style>
    #white {
        border: 20px solid #eee;
    }
    </style>
</head>
<body>
    <p id="red">Howdy?</p>
    <script>
        const pEl = document.getElementById("p");
        const cssAttr = "" +
        "color: red; background-color: green;";
        pEl.textContent = "Hello World!";
        pEl.setAttribute("style", cssAttr);
        pEl.setAttribute("id", "white");
    </script>
</body>
</html>
...

In the above example, we're adding two attributes to the HTML Element by using the .setAttribute method. Investigate the code very well before continuing with the rest of the lesson.

Next up, to add JS code to HTML. This is a very broad topic, as we still have to think in terms of Events, Functions, e.t.c. But to make it short, we're going to explain just briefly some basic examples as we'll go into further details in the future.

We can easily use the setAttribute method to add JS to our elements, but instead of it being like other attributes, we make use of events. Let's check an example:

...
<!DOCTYPE html>
<html lang='en'>
<head>
    <title> A Simple Webpage </title>
</head>
<body>
    <button onclick="alert('Hello World')">Howdy?</p>
</body>
</html>
...

The onclick attribute here fires up whatever is in it's value (Executing them as JS Code). However, onclick is not just an attribute, it is an event that fires up whenever we click the button. Go ahead and click the button, the code -- alert("Hello World") -- gets fired. Now take a look at how to achieve the same functionality with setAttribute method:

...
<!DOCTYPE html>
<html lang='en'>
<head>
    <title> A Simple Webpage </title>
</head>
<body>
    <button>Howdy?</p>
    <script>
        const btn = document.querySelector("button");
        btn.onclick = () => {
            alert("Hello World")
        }
    </script>
</body>
</html>
...

Now the code might seem absurd, but take a look at it very well, instead of just calling a method or function, we add a whole function so now we can go ahead and add more to that block of code (Clicking event can now execute more than 1 function, add another alert to the function or any code you want and it will run effectively)

Before learning how to create a node, try and add the click event to the above element using setAttribute method. This helps reinforce the learning. (Note: We'll talk about events in the future lessons)

To create a node, we have many ways for some elements (e.g Audio and Video). But before that, in the last example we're making use of setAttribute shortcut which is 'element.property = value'.

Let's go ahead and create an element.

...
const element = document.createElement(elementName);
...

Example of the above syntax:

...
const p = document.createElement("p");
...

Don't forget, If we don't put strings in quotes they're treated as variables.

Now we've created a paragraph element, the next step is to add it to the page and one way to do this is to add it as a child of another element. This is actually how we add most contents to the page using pure HTML. For example, the body tag is nested to the HTML (or root) tag. The title tag is nested to the head tag. (Note: Nested means putting one element inside another element)

Let's try to add the above paragraph element we created earlier as a child of the body tag.

...
const p = document.createElement("p"); document.body.appendChild(p);
...

Now, you may be thinking, "Why the heck is the element not showing up yet?". It's actually already on the page right now, what was needed to be done was to add a text (as the content) to the paragraph. Let's go ahead and write Hello World to the page.

...
const p = document.createElement("p"); p.textContent = "Hello World"; document.body.appendChild(p);
...

Voila! We got the element displayed correctly. You can also log the node to the console directly to watch how changes in properties or methods affect the node.

And now to the main and most important part of the project, the "Functionality". First of all, we need the button element, the paragraph to send the message back to the user (notice the element with the id of "message"), the textarea to get the text the user enters. Let's do just that.

...
let text = document.querySelector("textarea");
const message = document.getElementById("message");

calcBtn.onclick = () => {
    alert("Button Clicked!!!");
}
...

I believe we completely understand the above snippet of code. Now, when we clicked the button we don't want it to alert anything. We want to count the length of the text the user enters and output it as the text content of the message variable (Message now refers to a node).

So, how'd we achieve this? Simple! Get the value of the textarea (the text), get its length and output it. Super easy! Below is the revised function:

...
...
calcBtn.onclick = () => {
    const lettersFound = text.length;
    message.textContent = "Letters: " + lettersFound;
}
...
