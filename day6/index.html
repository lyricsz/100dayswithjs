Tutorial

DOM or Document Object Model is an API, that let us interact, create and manipulate our Objects on a page. Objects here refers to everything our page consist of. From the style (CSS) to the scripts (JS) to elements (HTML). But most importantly, it is used in retrieval, creation and manipulation of elements in our web page (not limited to only elements).

To really understood this, let's take a look at what our web page does under the hood every time we create a web page. Let's take a look at below code:

...
<!DOCTYPE html>
<html>
<head>
    <title> A Simple Webpage </title>
</head>
<body>
    <h2>Hello World</h2>
    <p> A simple "Hello World" page. </p>
</body>
</html>
...

Your result when you run the page should look like this:

If you have no idea what HTML is, you can take a crash course on it on W3C or on HTML with PJ Dev.

A simple web page has been created but what was going under the hood? Well, as far as we're concerned, what was going under the hood is that our web page was translated into a tree-like structure for us. This can let us use the dom api's to perform basic operations such as deletion or additions (appending) of new elements, manipulations of elements and trust me , the list goes on! A basic representation of our code below in a DOM Tree (The tree-like structure of our DOM is referred to as DOM Tree in, well, Web Development World):

A tree in general is contain of what we call "Nodes"... It's actually a not-so difficult concept (Don't let the name scares you). Normally, in HTML when we add an element to a web page, we added a new node actually. Imagine the paragraph element in the above code... (The Paragraph element in the code above has what content? ), it has an opening tag, a closing tag and content. We can add attributes to it to further add some information and definition to it (e.g title or style -- inline style)... That's all. For the HTML part, but for the JS Part, what we added is more than just element... It's a Node. A Node is really nothing more than element, but contains a lot than normal elements.

There is another important thing to understand about our DOM Tree. (Before we move on to the fun part):

A tree-like structure only has a node as its parent. In our above diagram, that's the document. The document has two nodes (think of the document as the root tag, because that's what it is) as its child. The childs are the "Head" and the "Body". The document is the parent of these childrens. But that's not the end, the children also has children... The Head has a children (the Title), The body has two children (the H2 and P). What is the Document (the root) relation to the P? If you think of grand-parent, you're absolutely right. Think of the family tree we're taught back in our first 6 grades, the tree structure is not so different from a family tree.

To give you a hint of this structure, think of moving up as going to parent (I'll be using traversing as moving up or down) and traversing down as going to children/childrens/none.

If an element "2" is nested to another element "1" (I'll be naming elements from now on, for better accumulation), it becomes the children and that element now has a parent (the element it was nested to). Suppose that nested element also has another nested element named 3, well, 3 is the child of 2 and 2 is the parent of 3. 1 is the parent of 2 and 1 is the grand-parent of 3.

Manipulating The Content of Element

First of all, in order to manipulate the content of an element (Grasping the knowledge of HTML element, Tags and Content is as easy as... possible), we need to understand how we can get that element. There are many ways to get an element using JS (Think of them as selectors in CSS).

Getting an element by it's tag name is the simplest way (well, it depends) to get a target element. The best thing to do when accesssing an element or array of elements (more on that later) is to assign that node to a variable. You can easily log the variable to see the available methods and properties of that Node (They varies ). To get an element by it's tag name, use the following syntax:

...
const bodyEl = document.querySelector("body"); #body is the element that want to be retrieved.

The document provides alot of helpful method, if you're curios you can log the whole document inside of a console to get a view of what properties or values are available. (We'll delve deeper into DOM in the future). The below code is for curious people only:

...
console.log(document);

If it doesn't display as a normal object would, a trick will be to use the window. Access the document property of the window and you'll be good to go. (To access the document property of the window object , use window.document). If it's still not logging correctly, log the window first (use window -- console.log(window)) then access the document property of the window. Below is the log of the document on Google chrome:

You can poke around this , most importantly you should be able to access some properties of the document by now -- this is a proof you get a good grasp of Objects data type. Now let's go back to our previous code, I meant this one:

...
const bodyEl = document.querySelector("body"); //body is the element that want to be retrieved.

The querySelector method (or function) of the document takes in an input just like a CSS. But we can also then use just the tag name... By saying it accept the parameter just like a CSS selector, I meant those " . " (for class selector) and " # " (for ID selector) among others but excluding some.

The querySelector returns the first element with the selector we pass in as the argument. To select all element using a tag name, we use querySelectorAll and pass in the tag name (always in quote, to avoid confusion with a variable name... and who knows? Yours might be a variable instead -- in above code, you could have a variable with the value of "body" you could easily replace the parameter with that variable e.g document.querySelector(bodyTag); )

Another way to select an element using their tag name is to use the following syntax:

...
const bodyEl = document.getElementsByTagName("body"); //body is the element that want to be retrieved.

Just pass in the tag name. What we got in return is not just the first element as in the querySelector, but an array of element(s). To loop through (by loop through, I meant to access all the element of an array) the array, we can use a for-loop or other looping concepts but since we haven't discussed about repitition, we're going to use a method provided by the array data type. The method is forEach. forEach let us cycle through an array. But first let's try out examples with a querySelector. (querySelector accept parameters like a ). The first example access the P element *P short for paragraph* and changes its text. We'll discuss more on manipulation later, this example is just to give you an idea of how we use JS to interact with a web page.

And we want to access all its elements, we can use forEach method of an array to perform exactly just that.

...
const a = ["Sherlock Holmes", "Mycroft Holmes", "John Watson", "Moriarty"];
a.forEach(el => {
    <console.log(el);
});
...

I know the above code must look cryptic, but it's really not. The function (forEach method) takes in a function (I've used the arrow function here, more on that when we study Functions), the function needs a parameter, this parameter we can then use to perform whatever operations we wish to perform (All operations must be inside the second function code-block).

...
array.forEach(function(a){
    //perform operations on "a"
})
...

The array calls our function on all elements with a being the value of what current element it is accessing. It access them accordingly. In our example (not the one above), our el first equals "Sherlock Holmes", then "Mycoft Holmes", followed by "John Watson", then "Moriarty". The getElementsByName method of the document accepts the name of the element(s) we're targeting. It returns an array containing those element(s) (As a node).

Now that we've discussed the basic ways of retrieving a Node, let's talk about manipulating a Node. We're going to discuss how to manipulate only it's content today, as we'll discuss about how to manipulate its Attributes, CSS and JS in day 7. (We'll be splitting this DOM Part into two to avoid cluttering).

We'll be using getElementById the most in this tutorial. Feel free to follow along or use other method you prefer to work with. To change the text of any element, we can modify the textContent property of that node (Casing in JavaScript matters, we can already note that built in methods use camelCase for naming things).

...
<!DOCTYPE html>
<html>
<head>
    <meta charset='utf-8' />
    <title> A Simple Webpage </title>
</head>
<body>
    <h2 id='greetingsEl'>Hello World</h2>
    <script>
        const name = prompt("Enter your name: ");         const greetingsEl = document.getElementsById("paragraph");
        greetingsEl.textContent = "Hello " + name;
    </script>
</body>
</html>
...

Above code may looks cryptic at first. I'll assume we all knew HTML5. So, let's break down the code part (JS Part):

  • The const name = prompt("Enter your name: ") send a prompt to the user (visitor) with a hint to enter his/her/it name.
  • The second line get an element with an ID of "paragraph". In our case that is the (//)
  • The third line changes the content of that element to "Hello " + name. Since name is being replaced with the user's name.

You can try adding tags directly to the textContent property of a Node. But it won't work. It only expects a text. It'll treat anything it saw as a text not as an Element. To add element as the content of our Node, we modify the innerHTML property of our Node. Here, where we put our Tag, will be replaced by that tag (Don't forget to wrote them as you'll have did using HTML).

...
<!DOCTYPE html>
<html>
<head>
    <meta charset='utf-8' />
    <title> A Simple Webpage </title>
</head>
<body>
    <h2 id='greetingsEl'>Hello World</h2>
    <script>
        const name = prompt("Enter your name: ");         const greetingsEl = document.getElementsById("paragraph");
        greetingsEl.innerHTML = "Hello " + "<i>" name + "</i>";
    </script>
</body>
</html>
...

Voila! You can go ahead and add other tags to it. We'll discuss about other methods of doing this, alongside how to modify or add attributes to a Node, how to modify / or add CSS and JavaScript to a Node and I'll see you in the next lesson.
