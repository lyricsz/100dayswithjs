Tutorial

Data types are so essential in understanding programming languages. You'll come acrosss it in almost any program you wrote.

Data types are the type of value stored in a data. There are predefined operations such as function and properties that comes with each types, and there are also do's and don't that comes with each data types.

JavaScript has the following data types:

  1. Number
  2. String
  3. Boolean
  4. Array
  5. Obects
  6. Function
  7. Undefined

Before we learn these data types, let's first understand some important thing about them.

  1. There are limits to the value some data types can store. E.G Numbers can only store some certain number, but have issues with storing large numbers or very small numbers.
  2. You can convert a data from type a to type b if such conversion is syntactically, and semantically correct. E.G You can always convert a number to a string but not vice versa. This is known as "Type Conversion" in programming languages.
  3. You cannot use some operations that are invalid on some certain types. E.g You can use the addition operator on two string but not the division operator. (More on operators in the future)
  4. You can always check the type of a data by using the 'type checker function' provided in the programming language you are using. In JavaScript, we use the 'typeof function' to know the type of our data. Almost every programming language has this.

Numbers

Numbers data type obviously are numbers. These data type is just number. You can have any number stored in your variable. The way we stored a number is by just typing-in the number without adding any quotes. By doing this, our variable now has the data type of a number which gives us access to alot of methods, properties, and even some operations on the data.

E.g Let's say i want to store my age in a variable, it would be unwise to use any data type apart from number... Since my age is a number. (Don't forget always use the right data type) I'll declare it like this:

...
const myAge = 24;
alert(myAge);
...

Now, i know we all might be wondering 'Why not just put quotes to 24 making it "24" '? Actually, that will turn our data from number into a sting and whatever operations comes built-in to numbers we cannot use it anymore, we'll have to stick with that of a string. (More on string in later sub-headings)

So, now that we've learned about how we can declare our variable with a number data type, let's check it out if it's actually a number or not using the typeof keyword. This check the type of our variable and return it's type. Some built-in function return a value while some don't. You can also create your custom function (More on those in the future)

...
const myAge = 24;
alert(typeof myAge);
...

Alright, what was the result? Number? Or other data type listed above?

There's alot you can do with numbers. These include but not limited to:

  1. Performing math operations. E.g 2 * 2 or 2 + 2 (* is used to indicate multiplication in JavaScript)
  2. Using relational operators with it. (Note: We'll talk about Relational operators in the future). E.g 2 > 3
  3. Conversion to string or boolean. You can easily convert a number to string or boolean.

And lot more that we'll see in the upcoming lessons

String

A String might sound quite new to you if you're just starting out in programming. Yet, a String only means Text. Now, you can call anything text. But you'll still have to be careful with a few things.

To make our data a string, we'll just have to sorround it with quotes. You can use both single quotes or double quotes, all are welcomed. But pick one and stick to it. We programmers call it "STYLE". So, go ahead and choose your style.

...
const language = "JavaScript";
const greetings = "Greetings from the realm of " + language;
alert(greetings);
...

Now, i know we might be suprise adding a string with a string doesn't give us an error. The addition of one string with another sting results in a new string with the addition of both. This is known as string concatenation. (String concatenation is the process of joining two or more strings together to produce a new string).

To further explain this, let's look at below example:

...
const stringA = "I am the first string";
const stringB = "I am the second string";
const stringC = stringA + " " + stringB;
alert(stringC);
...

I hope that explain things better. A quick question, "How many strings do we join together in the above example?". Be careful, you might thought it was 2 at first, but the answer is 3. We also add a space to the middle. Space is enclosed in quotes which makes it a string.

A very quick fun task is to go back to day 2 project, check the output, How many strings are concatenated in each output?

Now, let's talk about escape characters. We've already learn how to use strings in our project. But what if we want to include a quote in our string? The below code will give us error when executed:

...
const language = "JavaScript";
const greetings = "Greetings from the realm of " " + language + " " ";
alert(greetings);
...

I expect an error in the program. But we have a good intention, we want to enclose our language in quotes.

???

You might be wondering why we encounter an error. Take a look at the code, you'll notice we actually include the same quote we use to declare string to our string which confuses the interper (the web browser) by telling it we've ended our string before we actually end it.

A quick fix to this is to use single quote instead of double quotes.

...
const language = "JavaScript";
const greetings = "Greetings from the realm of ' " + language + " ' ";
alert(greetings);
...

But we don't want a single quote, we want to use double quote. To fix this, we use the escape characters. We have quite a few of them. Some examples are shown below:

Escape characters and their uses
\' Used to include a single quote in our string while avoiding any conflict
\" Used to include a double quote in our string while avoiding conflicts
\t Used to include a tab to our string. Mostly used with the console.log method
\n Indicates a new line. Mostly used with the console.log method

The list is exhaustive as almost anything can be escaped. Now to fix our earlier problem, let's use the escape character \" to include a double quote in our string.

...
const language = "JavaScript";
const greetings = "Greetings from the realm of \" " + language + " \" ";
alert(greetings);
...

And Voila, the bug's been fixed. Now, before we finish this sub-section, let's quickly talk about a useful properties of strings... Length

To figure out the length of any string, just access it's lenth properties.

To access the length property of any string, just use this syntax:

String.length

Let's take a look at a quick example:

...
const name = "John Doe";
const nameLenght = name.length;
alert("Your name is " + name);
alert("The length of your name is " + nameLenght);
...

Now, i know what you might think. The length is actually 7, not 8... In reality, even a space is a text (or characters)... Now, recount with a space and you'll get an eight.

Boolean

Boolean (also known as logic) is named after the legendary George Boole. The boolean value is so easy to understand. It can only have two value, "true" or "false" (Note, do not put any quote to it so as not to confuse the interpreter that it's a string).

In other words, it can either be this:

...
const bool = true;
alert(bool);
...

Or this:

...
const bool = false;
alert(bool);
...

Boolean are so important, as we'll see later on in Relational operators. Some other functions also return true or false in JavaScript. To change the value of a boolean, we can negate it using the Not logical operator, or we redeclare it.

The first example (Using the not operator -- !):

...
let bool = false;
bool = !bool;

alert(bool);
...

The Not operator changes the value to the opposite. In other words, it changes truth to false and false to true.

The second example:

...
let bool = false;
bool = true;
alert(bool);
...

Boolean are so important in your programs, you might want to do something if something is true or do other thing if it's false.

As we close this sub-section, don't forget that booleans can only store two values, True or False.

Task

Welcome to the most amazing task. We'll build a character counter. It accepts input... converts the input to text and checks out it's length and then gives out the length as the result.

We're not going to convert the input to text, because we're going to use the prompt function which automatically returns a string.

The prompt method of the window send a prompt to the user, this allow the user to input anything ranging from text to numbers, e.t.c. It send a return value. We can actually use that return value in a variable.

I know this might sound a little bit complex but it's not. The function does what it does, but it returns a value to us. This value is actually what the user types.

A brief example is this:

...
const age = prompt();
alert("Your age is " + age);
...

If you want to sent some hint, or message to the user so they can know what to input, just put your message (your message must be a string) as an argument to the prompt function.

...
const age = prompt("What is your age?");
alert("Your age is " + age);
...
